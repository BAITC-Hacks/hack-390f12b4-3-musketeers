# Модель и допущения

Модель фиксирована для всех пользователей: dataset-v1, 100 усл. ед., 8 кварталов.
Доли населения: Есиль .27, Алматы .24, Сарыарка .20, Байконур .13, Нура .16.
Все десять показателей направлены одинаково: больше — лучше.
Базовые оценки районов: 62.99, 57.06, 54.65, 56.63, 49.18.

Локальный эффект применяется в одном выбранном районе; городской — в каждом.
Цена городской меры учитывается один раз. Полный эффект умножается на (8−L)/8,
после чего прибавляются фиксированные синергии. Ограничение показателя 0–100
выполняется после общей суммы, включая отрицательные эффекты.

Синергии:
- M1 + M2: T1 +2 в районе M1.
- M10 + M12: B1 +2 в районе M10.
- M5 + M6: E2 +2 в районе M5.

Несовместимости:
- M1 и M3 во всех районах.
- M4 и M7 только в одном районе.
- M5 и M13 только в одном районе.

Веса: T1 .10, T2 .10, E1 .09, E2 .11, S1 .11, S2 .11,
B1 .09, B2 .09, C1 .10, C2 .10.

Score = .7 × среднее по населению + .3 × минимальный балл − число значений <40.
Порог строго меньше 40; значение ровно 40 не критическое.
Наиболее слабый район определяется заново для каждого сценария.

## Проверяемый пример

M7, M8, M10 — Нура; M12 — город; M5 — Сарыарка.
Стоимость 95; Score 56.54307; дельта 3.98539.
Вклад изменения среднего: .85064; минимума: 1.13475; снятия штрафа: 2.
Нура: школы 48, медицина 43.75, улицы 67.5, дорожная безопасность 51.75.

Нулевой набор разрешён только как база сравнения/черновик.
Финальный пользовательский сценарий требует ровно пяти решений.

## Рекомендации

Перебираются замены каждой из пяти мер: любая разрешённая мера и каждый её район.
Также проверяется смена района существующей меры. Кандидаты проходят общий
валидатор и математический движок. Возвращаются до трёх улучшений по Score,
при равенстве — меньшая стоимость, затем стабильный идентификатор.
Поиск локальный; отсутствие улучшений не доказывает глобальную оптимальность.

Прямые эффекты выводятся в показателях. Из-за минимума, критических порогов,
синергий и clip индивидуальные вклады в Score не являются аддитивными.
Итог объясняется точной декомпозицией трёх компонентов формулы.

## Следующий шаг для реального применения

Калибровка эффектов на наблюдаемых данных; сроки, капитальные и эксплуатационные
затраты; интервалы неопределённости; оценка сценариев совместно с городскими
специалистами. Текущие числа не обосновывают реальные бюджетные решения.
