# Использование AI

## При разработке

Codex использовался для анализа задания, программирования, тестов и документации.
Первоначальный Python MVP команды доработан без переписывания истории Git.
ChatGPT помог подготовить техническое задание.
NVIDIA API и Gemini в исполняемый продукт не подключены.

## В продукте

Провайдер OpenAI, официальный Python SDK; Responses API со Structured Outputs.
Модель задаётся OPENAI_MODEL, ключ — OPENAI_API_KEY.
Документация: https://developers.openai.com/api/docs/guides/structured-outputs

Сервер сам пересчитывает входной сценарий и рекомендации.
Модель получает каталог фактов с идентификаторами и проверенные альтернативы.
Ответ проверяется по схеме, ссылкам и идентификаторам кандидатов.
AI выбирает кандидатов для рекомендации, а описание их точных эффектов
формируется сервером по разнице показателей двух сценариев.
Числа в тексте проверяются по цитируемым фактам, включая округление для показа;
неизвестные значения отклоняются. Числовые карточки рендерятся из движка.
Проверка ссылок не гарантирует правильную интерпретацию текста моделью.

Один вызов по явному запросу; тайм-аут 20 секунд, автоматических повторов нет.
Максимум ответа 2200 токенов, store=false, ограниченный кеш.
Ни секреты, ни сторонние файлы не включаются в запрос.

## Статус проверки

Расчёт и резервный режим проверены. Успешный ответ, ошибка, неполный ответ,
неверные ссылки и выдуманная рекомендация проверены подменённым провайдером.
Живой вызов подтверждён 23 сентября 2026 года на локальном стенде:
модель gpt-4o-mini, HTTP 200, source=openai, cached=false.
Ответ принят только после проверки схемы и ссылок на факты.
Ключ сохранён исключительно в локальном .env и не включён в репозиторий.
Экспертам потребуется настроенный стенд или собственная конфигурация API.
Эта проверка подтверждает доступность провайдера на момент вызова.
