# Проверка версии

Среда: Windows, Python 3.12.14, зависимости из requirements.lock.txt.

## Автоматические проверки

- 32 теста pytest: формула, базовые значения и контрольный пример;
  перестановки решений; неизменность исходных данных; бюджет; число мер;
  повторы; направления; городские и районные эффекты; синергии;
  несовместимости; clip; критический порог; смена слабейшего района.
- Серверные запросы: отклонение клиентской цены, неверных правил, большого
  тела и некорректного JSON; отсутствие LLM-вызова для невалидного набора.
- Рекомендации повторно проверяются общим валидатором и движком.
- AI с подменённым провайдером: корректный JSON, кеш, неполный ответ,
  ошибка, неверные ссылки, числовая галлюцинация и несуществующий кандидат.
- Компиляция Python-модулей.
- UI-прокси: точный Score, сохранение ошибок бюджета и набора правил,
  ограничение тела запроса, отсутствие доступа к приватным файлам и ошибка при недоступном backend.
- Экспорт через HTTP attachment: повторная проверка сценария, JSON, лимита размера.
- Проверка синтаксиса браузерного JavaScript командой node --check.

Есть предупреждение совместимости о deprecated alias BlockingPortal
в установленной версии Starlette/AnyIO; проверки проходят.

## Проверка в браузере

Новый HTML/CSS/JS-интерфейс проверен через run.py с портами 8010/8510.
Финальный UI запущен отдельно на 8511 с существующим backend на 8000,
поскольку старые локальные процессы удерживают стандартные порты.
Начальное состояние: 0/5 решений, бюджет 100, Score 52.56.
Загрузка примера: 5/5, бюджет 95, остаток 5.
Итог: Score 56.54, прирост 3.99, критических значений 0.
Проверены отображение декомпозиции, недоступность шестой меры,
поиск 117 допустимых замен и явно обозначенный резервный отчёт.
Лучший найденный вариант для примера: 57.20556 при бюджете 100.
Проверены добавление инициативы с предварительным расчётом, восстановление
плана после обновления, сохранение именованного сценария и его отображение
в сравнении, импорт JSON, применение рекомендованной замены (Score 57.21).
Экспорт проверен через браузерное событие download после перехода
с blob-ссылки на HTTP attachment; скачиваемый сценарий повторно проверяет backend.
Шестая мера отклоняется; замена M12 на M13 в примере отклоняется из-за
превышения бюджета на 9. Кнопка применения недоступна.
Проверены широкий экран и мобильный viewport 390×844. Горизонтальной
прокрутки в мобильном результате нет. В браузерном журнале ошибок нет.
При проверке нового интерфейса AI вернул резервный отчёт; он явно обозначен
как локальный и не выдаётся за ответ модели.

При предыдущей проверке backend живой вызов OpenAI gpt-4o-mini подтверждён: HTTP 200, source=openai,
cached=false; ответ прошёл валидацию схемы и ссылок.
Проверка pip check не обнаружила нарушений зависимостей.
Подробности AI — в ai-usage.md.
Успешные локальные тесты не означают, что GitHub Actions уже прошёл.

из requirements.lock.txt. Зависимости скачаны заново, установка завершена,
