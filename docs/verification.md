# Проверка проекта

Проверено локально на Windows с Python 3.12 и зависимостями из `requirements.lock.txt`. Основной запуск — `python serve.py`, один сервер по адресу `http://127.0.0.1:8520`.

## Автоматические проверки

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m compileall -q backend frontend serve.py run.py
node --check frontend/web/app.js
```

Результат текущей проверки: **38 passed**, `pip check` — `No broken requirements found`, компиляция Python и синтаксис JS — без ошибок. Pytest показывает предупреждение о deprecated alias `BlockingPortal` в установленной версии Starlette/AnyIO; оно не влияет на результат тестов.

Тесты покрывают формулу и контрольный пример, правила и конфликты мер, бюджет, порядок решений, порог критического показателя, события, рекомендации, API-валидацию, защиту от подмены готового Score, AI-ответы с подменённым провайдером, лимиты, SQLite-рейтинг и маршруты единого сервера. Тесты **не делают платных вызовов AI**.

## Проверка запущенного сервера

На `http://127.0.0.1:8520/api/health` получены `status=ok`, `ruleset=dataset-v1`. `/api/data` вернул **5 районов**, **14 мер** и бюджет **100**. `/api/preview` для встроенного примера вернул `complete=true`, стоимость **95** и Score **56.54307**. Страница `/docs` доступна и содержит Swagger UI.

В браузере ранее проверены полный план, расчёт результата, поиск улучшений, блокирование недопустимой замены, сравнение и JSON, событие «Суровая зима», рейтинг команд, AI-разбор и локальный резервный отчёт. После редакционного редизайна отдельно проверены карта, страница инициатив, замена меры и отзывчивая сетка каталога на широком, среднем и мобильном экране. Горизонтального переполнения на проверенных ширинах нет.

Живой вызов OpenAI на локальном стенде был подтверждён 23 сентября 2026 года: `source=openai`, `model=gpt-4o-mini`, ответ прошёл проверку структуры и ссылок. Это подтверждает работоспособность **в тот момент**; для повторения необходимы рабочий API-ключ, доступ к модели и сеть. Без этого сервер выдаёт явно обозначенный резервный отчёт. Детали — в [ai-usage.md](ai-usage.md).

## Не проверено или требует внешнего действия

- GitHub Actions настроен, но запуск не начался из-за сообщения GitHub о блокировке аккаунта по биллингу. Локальные успешные тесты нельзя считать зелёным CI.
- Dockerfile и Compose подготовлены; сборка контейнера на текущем компьютере не выполнялась, поскольку Docker не установлен.
- Публичный хостинг не подключён. Локальная проверка не заменяет проверку HTTPS, постоянного диска и доступа жюри на опубликованном стенде.
