# Проверка версии

Среда: Windows, Python 3.12.14, зависимости из requirements.lock.txt.

## Автоматические проверки

- 27 тестов pytest: формула, базовые значения и контрольный пример;
  перестановки решений; неизменность исходных данных; бюджет; число мер;
  повторы; направления; городские и районные эффекты; синергии;
  несовместимости; clip; критический порог; смена слабейшего района.
- Серверные запросы: отклонение клиентской цены, неверных правил, большого
  тела и некорректного JSON; отсутствие LLM-вызова для невалидного набора.
- Рекомендации повторно проверяются общим валидатором и движком.
- AI с подменённым провайдером: корректный JSON, кеш, неполный ответ,
  ошибка, неверные ссылки, числовая галлюцинация и несуществующий кандидат.
- Компиляция Python-модулей.

Есть предупреждение совместимости о deprecated alias BlockingPortal
в установленной версии Starlette/AnyIO; проверки проходят.
