# Как трактуются пять направлений

В кратком задании перечислены пять направлений развития. В предоставленном
подробном датасете допускаются максимум две меры одного направления и минимум
три направления. Основной режим dataset-v1 следует подробным правилам датасета:
ровно пять разных мер, максимум две в одном направлении. Это автоматически
обеспечивает минимум три направления.

Поскольку формулировку задания можно понять и как «ровно по одной мере из каждого
направления», реализован режим one-per-direction-v1. Он включается владельцем
сервера через RULESET=one-per-direction-v1. Клиент не может обойти выбранный режим:
несовпадение ruleset отклоняется сервером. Пример адаптируется автоматически.

Подтверждение организаторов не получено. До их разъяснения основной режим —
dataset-v1. Все команды одного соревнования должны использовать одинаковый
режим. Общий рейтинг разделён по правилам и событиям, смешивать оценки нельзя.

События winter-v1 и growth-v1 — дополнительные авторские учебные условия.
Режим none сохраняет официальный синтетический датасет без изменений.
