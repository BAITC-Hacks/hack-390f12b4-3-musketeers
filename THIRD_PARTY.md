# Сторонние материалы

Синтетический датасет, формула и каталог мер предоставлены участником
для задания HackAlem AI / Astana Innovations. Команда не выдаёт их за
собственные реальные исследования или данные городских служб.
Условия использования исходных материалов определяются организатором;
отдельная лицензия на датасет во вложении не указана.

Основные библиотеки и лицензии по метаданным установленных пакетов:

| Компонент | Версия | Лицензия |
|---|---|---|
| FastAPI | 0.115.12 | MIT |
| Uvicorn | 0.34.2 | BSD-3-Clause |
| Pydantic | 2.11.4 | MIT |
| OpenAI Python SDK | 1.78.1 | Apache-2.0 |
| pytest | 8.3.5 | MIT |
| HTTPX | 0.28.1 | BSD-3-Clause |

Полный список зависимостей закреплён в requirements.lock.txt.
Тексты лицензий и уведомлений транзитивных пакетов сохраняются в их
установочных дистрибутивах. Эта таблица не заменяет их условия.
Интерфейс, SVG-иконки и условная схема написаны для этого проекта на HTML/CSS/JS.
Внешние шрифты, CDN, картографические сервисы и JS-библиотеки не требуются.
Готовые сторонние шаблоны продукта и картографические данные не использованы.
Для API OpenAI действуют условия соответствующего сервиса отдельно от
лицензии SDK.
